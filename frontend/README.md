# RacingLineAI Next.js Frontend

Modern, high-performance F1 analytics dashboard built with Next.js 14.

## Features

- **Interactive Visualizations**: D3.js circuit layouts + Plotly charts
- **Real-time Data**: React Query for efficient data fetching
- **ML Predictions**: LSTM forecasting, regression analysis, strategy optimization
- **Dark Theme**: Optimized for data visualization
- **Responsive**: Mobile-first design
- **Type-Safe**: Full TypeScript coverage

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```

## Environment Setup

Create `.env.local`:
```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## Tech Stack

- Next.js 14, TypeScript, Tailwind CSS
- Plotly.js + D3.js for visualizations
- TanStack Query for data fetching
- Zustand for state management
